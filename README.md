# My Portfolio

🔗 [Live Demo](https://roselineonyeka-dev-portfolio.vercel.app/) · 💻 [GitHub](https://github.com/Roselineonyeka/my-portfolio)

My personal portfolio website — built from scratch with React and TypeScript to showcase my projects, skills, and experience as a front-end developer, and as a hands-on way to go deeper with React.

## Features
- 🌗 Light and dark mode with persisted theme preference
- 🖱️ Custom animated cursor trail (desktop)
- 📱 Fully responsive with a mobile hamburger menu
- 🧭 Scroll-spy navigation that highlights the active section
- 🎨 Bento-style project grid with hover animations
- 📬 Working contact form (Formspree) plus direct email/social links
- 💬 Floating WhatsApp contact button
- 📄 Downloadable CV
- 🏆 Certifications section

## Sections
- Hero
- About
- Projects
- Skills (Languages, Frameworks & Libraries, Tools)
- Experience
- Certifications
- Contact

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion (animations)
- Formspree (contact form backend)

## Getting Started

```bash
git clone https://github.com/Roselineonyeka/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Build

```bash
npm run build
```
